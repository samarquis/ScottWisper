<task type="auto">
  <name>Task 3: Implement custom actions for logging</name>
  <files>.wix/CustomActions.wxs, .wix/LoggingCA/CustomAction.cs</files>
  <action>
Create `.wix/CustomActions.wxs` and implement the custom actions:

**CustomAction.cs (in LoggingCA project):**
1. [CustomAction] methods:
   - LogInstallStart - Record installation initiation
   - LogComponentInstall - Log each component as it installs
   - LogErrorDetails - Capture and log error information
   - PreserveLogOnFailure - Copy log to permanent location if install fails
   - LogInstallComplete - Record successful completion
   - ValidateEnvironment - Check prerequisites and log results

2. Each action should:
   - Accept Session parameter
   - Write to session.Log for MSI log integration
   - Return ActionResult.Success (or Failure if critical)
   - Handle exceptions gracefully

**CustomActions.wxs:**
1. Define Binary element referencing the built DLL
2. Create CustomAction elements:
   ```xml
   <CustomAction Id="LogInstallStart" BinaryKey="LoggingCA" 
                 DllEntry="LogInstallStart" Execute="immediate" />
   <CustomAction Id="PreserveLogOnFailure" BinaryKey="LoggingCA"
                 DllEntry="PreserveLogOnFailure" Execute="deferred" />
   ```

3. Schedule in InstallExecuteSequence:
   - LogInstallStart: After InstallInitialize
   - LogComponentInstall: After each InstallFiles
   - PreserveLogOnFailure: On failure (custom condition)
   - LogInstallComplete: Before InstallFinalize

4. Use SetProperty to pass data to deferred actions (CustomActionData)

5. Add condition to only run logging in certain modes:
   - Not run in silent mode unless WHISPERKEY_ENABLE_LOGGING=1
  </action>
  <verify>grep -c "CustomAction Id=" .wix/CustomActions.wxs | awk '{print ($1 >= 4 ? "pass" : "fail")}'</verify>
  <done>At least 4 custom actions defined for logging at different install stages</done>
</task>
